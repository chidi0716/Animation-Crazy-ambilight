動畫瘋環境光

設定選單在影片播放器裡：
點擊動畫瘋播放器右下角控制列中，畫質按鈕左邊的環境光按鈕。

找不到設定按鈕

請重新整理瀏覽器中的網頁。

如果重新整理後還是沒有出現設定按鈕，可以開啟瀏覽器的 Console（按 F12），搜尋以「動畫瘋環境光」開頭的錯誤或警告。

排解效能問題

請參考疑難排解說明。
遇到其他問題或有建議，歡迎到 GitHub Issues 回報。
